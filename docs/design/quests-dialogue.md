# 任務與對話

狀態：v0.1 提案（2026-10-31）。內容包格式見 ZeWorld 的 `content-pack/schema.json`，文風給導演的版本在 `content/style.md`。這份文件給人寫手寫內容、也給調導演提示詞時參考。

## 任務結構

一個事件用內容包的 `stages`。寫的時候照這個節奏：

1. **鉤子**（一句話）：玩家一進場就知道發生什麼事。
2. **選擇或行動**：至少一個會改變結果的決定，或一場戰鬥。
3. **後果**：結局寫回因果（旗標、善惡、關係、`remember`），需要時送 `request_followup`。

規則：

- 每個事件至少一個「真的會改變後續」的選擇。不做所有選項都導向同一句話的假選擇。
- 失敗也是一種結局，不是重來：`on_fail`、`on_abandon` 要寫出世界怎麼反應。
- 獎勵跟著「做了什麼」走，不跟著「選了好人」走。殺伐也可以拿到好東西，只是後果不同。
- 一個事件 3～8 分鐘。長故事拆成多個事件，用旗標與 `days_since_flag` 串起來。

## 對話

### 文風

- 古風白話：句子短，像武俠小說的對白，不用文言長句，也不用現代詞、網路用語。
- 旁白只寫看得到的東西，一兩句，不替玩家感受。
- 每句台詞 30 字以內，螢幕一次顯示一句。

### 角色聲音

固定角色的設定在 `content/style.md`。寫台詞時用這張表檢查：

| 角色 | 說話方式 | 會說 | 不會說 |
| --- | --- | --- | --- |
| 青玄真人（師父） | 短、慢、常反問 | 「下山這幾日，心可還靜？」 | 長篇說教、直接誇獎 |
| 林清禾（師姊） | 直、快、愛比 | 「又偷懶？拔劍，我陪你練。」 | 撒嬌、示弱（除非關係很高） |
| 趙小乙（師弟） | 話多、一驚一乍、叫你師兄／師姊 | 「真、真的有狐妖？師兄你不怕嗎？」 | 冷靜分析 |
| 白蘅（狐女） | 客氣但疏離，關係高才會打趣 | 「恩公說笑了。」 | 現代口語 |

新角色加進 `content/style.md`，寫清楚「說話方式」和一句範例台詞。

### 選項

- 2～4 個選項。每個選項是玩家角色會說的話或會做的事，不寫「（善良）」這類標籤。
- 用 `show_if` 讓心性、關係、境界開出特別選項，例如正邪 ≥ 30 才有「親手擒下狐妖」。這讓玩家感覺角色是自己養出來的。
- 至少保留一個不表態的選項（沉默、離開），也要有後果。

### NPC 記憶

- 再出場的角色用同一個 `memory_key`；結局用 `remember` 寫下對方會記得的事。
- NPC 提起往事要具體：「三日前山崖下」，不是「上次的事」。
- 師父與同門會聽說玩家在山下做的事（已寫在 `content/style.md`）。宗門事件要引用至少一件玩家最近的經歷。

### 即時改寫（`live_rewrite`）

導演用 Sonnet 5.5 依玩家的經歷改寫標了 `live_rewrite` 的台詞（已上線）。手寫時：

- 只標「適合帶入個人經歷」的台詞（招呼、回憶、評價玩家），劇情關鍵句不標，避免改壞。
- 預寫版本要能單獨成立，因為導演沒開或還沒改好時顯示的是預寫版。

## 宗門差事模板

任務板的差事用模板＋導演填細節，省手寫量。模板寫在新的 `content/errands.json`（遊戲資料）：

```json
{
  "errand.deliver_medicine": {
    "title": "送藥下山",
    "region": "region.qingyun_foothills",
    "tier_range": ["煉氣", "築基"],
    "hint": "把丹藥送到山村某戶人家，路上可能遇到小麻煩，最多一場小戰鬥。",
    "reward": "loot.sect_reward"
  }
}
```

遊戲每天挑 3 個模板，請導演依模板生成當天的差事（用現有的 request tag 與 `expires_after_days`）。導演沒開時，用每個模板附的一個手寫版本。
