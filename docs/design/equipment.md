# 裝備品階與時裝

狀態：v0.1（2026-11-03）。Kc：「有些服飾裝備配件是需要獲取才有，然後對應的等級要有不同的效果區分，物品等級規劃要設計一下」。決策卡選「裝備加數值＋時裝分開」。

## 一、兩條線

| | 裝備 | 時裝（衣櫃） |
| --- | --- | --- |
| 資料 | `content/equipment.json`、`scripts/equipment.gd` | `content/wardrobe.json`、`scripts/wardrobe.gd` |
| 欄位 | 衣袍、腰封、護腕、鞋靴、頭冠、佩飾 | 上衣、下裳、外罩、腰封、護腕、鞋靴、頭飾、髮飾、肩飾、背飾、腰飾、容貌 |
| 有沒有數值 | 有，依品階 | 沒有 |
| 怎麼拿 | 掉落、差事、藏寶、事件；仙器／魔器走仙緣、魔緣機緣 | 境界、旗標、機緣、因果（照舊）；收費只碰時裝與緣分 |
| 身上看起來 | 每件裝備有一個 `look`（衣櫃同欄的選項） | 有裝備的欄位預設「隨裝備」；選別的就蓋在裝備上面 |
| 周身光效 | 看最高品階那件，時裝蓋不掉也裝不出來 | 無 |

存檔：`game_data["equip"]`（欄位 → 裝備 id）、`game_data["look"]`（時裝，`equip` 代表隨裝備）。擁有＝背包裡有這個物品名。

## 二、品階（跟兵器同一張表）

| 品階 | 對應境界 | 倍率（1＋0.25×階） | 詞條數 | 周身 |
| --- | --- | --- | --- | --- |
| 凡器 | 煉氣 | ×1.0 | 0 | 平常的青玉光暈 |
| 法器 | 築基 | ×1.25 | 1 | 光暈加亮 |
| 靈器 | 金丹 | ×1.5 | 2 | 淡藍光暈＋靈光點點 |
| 法寶 | 元嬰 | ×1.75 | 2 | 金光暈＋更多光點 |
| 仙器／魔器 | 化神 | ×2.0 | 2 | 仙：金光往上飄；魔：朱紅光暈與火星 |

名稱與倍率直接讀 `weapons.json` 的 `grades`、`grade_bonus` 同一套。衣櫃裡裝備名依品階上色（凡墨、法青、靈藍、法寶紫、仙金、魔朱）。

## 三、數值

| 欄位 | 底數（乘品階倍率） |
| --- | --- |
| 衣袍 | 氣血 6、護體 4% |
| 腰封 | 氣血 3、真元 4 |
| 護腕 | 護體 3%、氣血 2 |
| 鞋靴 | 身法 4% |
| 頭冠 | 真元 6 |
| 佩飾 | 回氣 15% |

詞條：氣血 5、真元 5、護體 3%、身法 3%、回氣 10%（也乘倍率）。上限：護體 45%、身法 25%、回氣 100%。
入門三件（青雲弟子袍、青雲腰封、黑布靴）是 `plain`：只是衣服、沒有數值，原本的戰鬥數值以它為基準，不必重調。

接到遊戲：氣血上限、真元上限（`main.player_max_hp/mp`）、受傷（`equipment_guard`，在功法減傷之後）、跑速（`player.speed_mult`）、真元回復。換上更好的裝備，多出來的氣血上限直接補上。

## 四、裝備清單與來源（22 件）

| 品階 | 裝備 | 來源 |
| --- | --- | --- |
| 凡器 | 青雲弟子袍、青雲腰封、黑布靴 | 入門 |
| 凡器 | 布護腕 | 山腳野怪、狌狌偷果差事 |
| 凡器 | 綁腿草鞋 | 山賊、山道剪徑差事 |
| 凡器 | 酒葫蘆、青雲抹額 | 散修遺物、宗門獎賞（藏寶） |
| 法器 | 鐵釘皮護腕、天青法衣、銀邊腰封、安魂玉佩 | 掉落表 rare（藏寶、事件） |
| 法器 | 狼皮快靴 | 狼妖、清剿狼妖差事 |
| 靈器 | 青玉護腕、束髮銀冠、護身符籙 | 掉落表 rare／epic |
| 靈器 | 踏影靴 | 蠱雕、蠱雕翎羽差事 |
| 法寶 | 雲紋道袍、金絲腰封 | 鎮妖司重賞、妖丹洞 epic |
| 仙器 | 流雲仙裳、蓮華冠 | 仙緣機緣事件 |

拿到時欄位是空的就直接穿上；已經有東西就放背包，Y 鍵【裝備】頁換。仙器／魔器跟兵器一樣守「緣分只買頻率」：免費玩家遇到機緣一樣拿得到，數值走同一條曲線。

## 五、還沒做

1. 仙緣／魔緣機緣事件內容包還沒寫，四件仙器／魔器目前只能測試給。
2. 品階詞條目前固定在 json；之後可以做隨機詞條或器靈事件（weapons-and-arts.md 的靈器器靈）。
3. 裝備的樣子借用衣櫃現有的件；高品階可以再畫專屬的件（例如法寶衣袍的流動雲紋）。
