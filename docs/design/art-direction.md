# 美術風格指南

狀態：v0.1 提案（2026-10-31）。路線已定為手繪 2D 插畫風；交付規格（尺寸、檔名、透明背景）寫在 [art/STYLE.md](../../art/STYLE.md)，這份文件講「要長成什麼樣、為什麼」。

## 方向：會動的水墨卷軸

不追求精緻寫實，要的是一眼認得出來。整個遊戲看起來像一卷正在展開的水墨長卷，角色是畫裡走出來的人。

五個特色，做任何美術決定時拿來檢查：

### 1. 卷軸與留白

- 畫面上緣與遠景淡到宣紙色，像畫沒畫完；不把整個畫面塗滿。
- 換地區時用「捲軸展開」或「墨暈開」轉場，不用黑畫面淡入淡出。
- 畫面四角有很淡的紙紋與暗角，戰鬥畫面也保留。

### 2. 字訣：法術以字成形

這是 Zetas 最主要的視覺記憶點。

- 施展術法時，先在角色前方一筆寫出一個字（火、雷、定、斬、渡），字再化成效果：「火」字燒開變成火焰，「定」字蓋下去成為定身符印。
- 每門功法有自己的筆法：劍訣是草書、法訣是行書、符籙是篆書、佛門是楷書。
- 劍氣、刀光是一道帶飛白的筆觸；打中時濺墨點，不用火花。
- 強化節點改變字的樣子（劍氣三道 → 三筆），玩家看得出自己的技能長了什麼。

### 3. 三道三色

仙、魔、佛各有一套顏色，機緣事件一觸發，畫面就往那個顏色偏，玩家一看就知道「仙緣來了」。

| 道 | 主色 | 點綴 | 筆觸 | 畫面感覺 |
| --- | --- | --- | --- | --- |
| 仙 | 月白、天青 | 淡金 | 輕、長、留白多 | 雲氣、鶴、光從上方灑下 |
| 魔 | 墨黑、焦茶 | 朱紅 | 重、濕、會滴 | 墨往下流、倒影、構圖傾斜 |
| 佛 | 赭石、沙黃 | 金箔 | 穩、圓、楷書感 | 背光、壁畫質感、對稱構圖 |

平常的畫面是低飽和的青、黛、赭（見 art/STYLE.md），三道的顏色只在機緣事件、相關地區與心法特效出現，才顯得特別。

### 4. 剪影先行

- 角色先看剪影：長袖、披帛、髮帶、劍穗是招牌輪廓，也是動起來的次要動態。
- 敵人剪影要一眼看出威脅（art/STYLE.md 已寫）。妖物保留一部分動物特徵，越強越不像人。
- 角色身上的細節少，臉部幾筆帶過；表情交給對話立繪。

### 5. 境界看得見

修為越高，角色的樣子跟著變，不用看數字就知道自己變強了：

| 境界 | 變化 |
| --- | --- |
| 煉氣 | 布衣、木劍，線條最樸素 |
| 築基 | 宗門制服，衣角開始有氣流 |
| 金丹 | 周身一圈很淡的墨氣 |
| 元嬰 | 腳下雲氣，施法時背後浮出字影 |
| 化神以上 | 依心性帶仙／魔／佛的顏色，輪廓會發光或滴墨 |

## 角色

- **比例**：成人約 1:7 頭身，偏修長；不要 Q 版、不要日系大眼。
- **線條**：毛筆線，轉折處粗、收尾細。外輪廓粗、內部線細。
- **上色**：淡彩平塗加一層水痕，不做漸層打光、不做賽璐珞硬影。光從左上來（art/STYLE.md）。
- **服裝**：以宋明服制為底，做簡化與誇張（袖子更長、披帛更飄）。各宗門有一個招牌顏色與一個招牌配件，青雲宗是青衣與白色劍穗。
- **對話立繪**：半身，比場景角色細一些，每個固定角色至少三種表情（平常、怒、笑或哀）。

## 場景

- 遠、中、近三層（art/STYLE.md）。遠景只用墨色深淺，中景加淡彩，近景是可以站的平台與前景遮擋。
- 每個地區一個主色（見 [世界地圖](world-map.md)），再加一個只屬於這裡的「招牌物件」：青雲宗的白石階、黑風嶺的枯松、雲夢澤的蘆葦、南疆的吊腳樓、蓬萊的浮島、血海的骨橋、靈山的石窟佛像。
- 時辰變化用整體色調處理（晨偏冷白、午偏亮、暮偏橙、夜偏藍黑），夜裡加燈籠、螢火、月光。

## 動畫

- 角色動作 8～12 格一循環，帶殘影格（筆刷拖影），不追求流暢的高格數。
- 待機時衣袖和髮帶要動；跑步時披帛往後拉。
- 受擊用墨點飛濺加角色短暫變成墨色剪影，死亡時散成墨霧。

## 介面

- 底是宣紙，邊框是細墨線，確認與重要按鈕是朱砂印章。
- 字型要可商用：內文可用霞鶩文楷 TC（SIL OFL）；標題可以另選書法字型，上架前確認授權。
- 氣血、靈力條畫成墨條；緣分值三條用三道的顏色，放在角色面板。
- 對話框半透明宣紙，立繪站在框外左右。

## 畫面可讀性

風格不能犧牲玩法：

- 背景對比低、飽和低；角色、敵人、可以互動的東西對比高。
- 敵人出招前一律有朱紅色的預兆（墨線、印記），玩家學一次就懂。
- 可以站的平台邊緣要有一條清楚的墨線；純裝飾的東西不畫這條線。
- 心魔幻境刻意傾斜、錯位，但地面仍然是平的。

## 參考（學它的什麼）

只學特質，不照抄畫面：

| 作品 | 學什麼 |
| --- | --- |
| 《小蝌蚪找媽媽》（上海美術電影製片廠，1960） | 水墨暈染怎麼動、留白 |
| 《中國奇譚》（2023） | 同一題材可以有很多種東方筆法，敢做風格 |
| 《大神》（Okami） | 筆觸本身就是玩法 |
| 《九日》（Nine Sols） | 東方題材的橫軸動作遊戲，角色在複雜背景前仍清楚 |
| 《GRIS》 | 用顏色表達進度與情緒 |
| 《空洞騎士》 | 剪影辨識度、前景遮擋與地圖層次 |

## AI 輔助與人工的分工

素材多、變體多（導演生成的 NPC 會分到同模板的不同變體），會用 AI 補量，但風格由人定：

1. 先由人畫或挑出約 20 張「定稿圖」（角色、場景、特效各幾張），當風格標準。
2. 只用這批自己的定稿圖訓練風格模型（例如 LoRA），不拿特定在世畫家的作品訓練，避免著作權與風格爭議。
3. AI 產出一律人工挑選、修圖後才進 `art/`，並用這份文件的五個特色檢查。
4. 字訣的字一律手寫或用授權字型描，不讓 AI 生成錯字。
