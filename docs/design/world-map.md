# 世界地圖與地區

狀態：v0.1 提案（2026-10-31）。目前已做的是青雲山脈的三個地區，其餘是規劃。

## 目標

地圖要「豐富」，在橫軸遊戲裡指的是四件事：

1. **地區夠多、夠不一樣**：每個地區一眼就認得出來（主色、地形、音樂、怪物、勢力）。
2. **每張圖有層次**：上下有好幾層平台、藤蔓、繩索、屋頂，不是一條平路走到底。
3. **有東西可以找**：暗道、高處的寶箱、要某個身法才上得去的地方、只在夜裡出現的路。
4. **會變**：同一張圖在不同時辰、天象、劇情階段會不一樣，導演也會把區塊重新組成事件專屬的場景。

## 世界結構

世界叫「九州」。玩家從青雲山出發，境界越高能去的地方越遠。一個大區包含 2～4 個地區（`content/regions.json` 的一筆），每個地區 3～8 個區塊（`content/chunks.json`）。

| 大區 | 地區（建議 id） | 適合境界 | 主色 | 地形與特色 | 勢力與怪物 |
| --- | --- | --- | --- | --- | --- |

### 中樞與移動

- 每個大區有一個城鎮當中樞（青雲宗、澤畔鎮、苗寨、仙島外灘、鬼市、千佛窟），有商人、任務板、傳送陣。
- 按 T 開地圖移動，花遊戲時間（現在 1～2 個時辰）。去新大區要先「開路」：主線事件或找到傳送陣才解鎖。
- 之後加御劍飛行：築基後可以在已去過的地區之間直接飛，時間減半。

## 一張地圖的做法

地圖由區塊左右接起來。目前每個區塊是一張背景加一條地面。要做出層次，每個區塊再加這些資料（遊戲端，引擎不需要知道）：

| 元素 | 說明 |
| --- | --- |
| 平台 | 浮空的木板、屋頂、樹枝、石台。至少 2 層高度 |
| 攀爬 | 藤蔓、繩索、梯子，按上下爬 |
| 身法門檻 | 要二段跳、御風、水遁、穿牆等身法才到得了的地方（見技能樹文件的「身法」） |
| 暗格 | 打破的牆、只有夜裡亮起的陣紋、要燒掉的藤 |
| 前景遮擋 | 竹葉、垂簾、霧，角色走過會半透明 |
| 地點 | 內容包用的 `pt.*` 點（已有） |

規則：

- 主路一定能用基本跳躍走完，身法只開支線與寶物。
- 每個區塊至少一個「回頭才拿得到」的東西，給後來學會身法的玩家回來找。
- 一個地區的區塊共用一種地形語彙，換大區才換。

## 會變的地圖

| 變化 | 怎麼做 |
| --- | --- |
| 時辰（晨午暮夜） | 色調濾鏡＋夜間專屬物件（燈籠、螢火、只在夜裡出現的路）。事件可用 `time_of_day` 條件 |
| 天象 | 雨、雪、霧、血月、雷雨。遊戲每天擲一次，當天的天象寫進旗標，事件可以用 `flag` 條件引用，例如血月夜魔緣事件機率高 |
| 劇情狀態 | 村子被妖襲過後變成廢墟版本；宗門大比期間廣場掛旗。用旗標切換區塊的變體圖 |
| 導演組場景 | 事件需要專屬場景時，從同地區挑 1～3 個區塊組成（已有，規則寫在 `content/style.md`） |
| 秘境 | 從一個大區的區塊庫隨機組 5～8 段的一次性地圖，盡頭有 boss 或寶物。每次進去都不一樣 |

## 區塊庫的規模

導演只能用區塊庫裡的區塊，所以區塊越多、標籤越細，生成的事件越不重複。

- 每個地區 6～10 個區塊，每個區塊 1～3 個地圖標籤。
- 每個大區 2～3 個「秘境專用」區塊（走廊、轉角、寶室、boss 房）。
- 標籤用一套共通詞：`forest`、`cave`、`village`、`shrine`、`water`、`peak`、`ruins`、`market`、`den`、`illusion`……新增標籤要同時更新 `content/style.md`，導演才知道能用。

全部做完約 25 個地區、200 個區塊。美術一張一張補，缺圖時畫色塊（已有退路）。

## 洞府

元嬰後（或仙緣線「雲中仙府」完成時）玩家有自己的洞府：

- 一個可以擺設的小地圖：丹房、藥圃、靈獸窩、靜室。
- 打坐在洞府內修為最快；藥圃每天長草藥。
- 收服的靈獸、救過的 NPC 可能來拜訪，導演可用洞府當事件場景。
