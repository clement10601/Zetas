# 功法與技能樹

狀態：v0.1 提案（2026-10-31）。現在遊戲只有近身攻擊（J）、打坐（M）、突破（B），數值在 `scripts/cultivation.gd`。

## 目標

- 每個玩家的角色要長得不一樣：選的功法、學的術法、走的心性都會影響打法。
- 技能要和地圖、事件綁在一起：身法開新路，緣法來自機緣事件，心性分支看因果。
- 導演生成的事件可以「傳授」技能，但只能從技能表裡挑，不能自己發明（跟掉落表同一套做法）。

## 四層結構

| 層 | 是什麼 | 怎麼得到 | 數量 |
| --- | --- | --- | --- |
| **功法**（主修） | 決定打法的主幹，一次只能主修一門 | 宗門傳功、機緣、拜師 | 煉氣時選第一門，之後可以轉修 |
| **術法** | 主動技能，放進快捷鍵 | 功法樹上的節點、功法殘頁 | 同時裝 4 個 |
| **身法** | 移動能力，開地圖 | 境界突破、特定事件 | 6 種左右 |
| **心法**（被動） | 依心性分成仙、魔、佛三支 | 心性到門檻自動開放，點數解鎖 | 每支 8～10 個節點 |

### 功法

第一門在煉氣時選（青雲宗傳功事件裡讓玩家挑）：

| 功法 | 打法 | 招牌術法 |
| --- | --- | --- |
| 青雲劍訣 | 近身連擊、劍氣 | 劍氣斬、御劍 |
| 五行法訣 | 遠程法術、範圍傷害 | 火符、冰錐、雷引 |
| 金剛體術 | 硬吃傷害、反震 | 金身、震地 |
| 符籙之道 | 佈陣、陷阱、召喚 | 定身符、紙人、困陣 |

機緣與主線之後還會開放：御獸（靈獸作戰）、魔功（以氣血換傷害）、禪功（佛緣，化解與淨化）。

每門功法是一棵 15～20 個節點的樹，分三段，對應境界：煉氣～築基、金丹～元嬰、化神以上。節點有三種：

- **術法節點**：學會一個主動技。
- **強化節點**：改變一個已會術法的行為（劍氣變三道、火符留下火海）。
- **轉折節點**：每段結尾二選一，決定這門功法往哪邊走（例如劍訣走「快劍」或「重劍」）。

### 術法與按鍵

| 按鍵 | 功能 |
| --- | --- |
| J | 普攻（隨功法變化） |
| U、I、O、L | 四個術法欄 |
| K | 身法（衝刺／閃避） |
| 跳（Alt／C／空白）在空中再按 | 依身法：二段跳、御風。↑ 留給爬繩梯、傳送點與交談 |

術法消耗「靈力」，靈力打坐或戰鬥中慢慢回。術法有冷卻，數值集中寫在 `scripts/cultivation.gd` 或新的技能資料表。

### 身法（開地圖）

| 身法 | 何時得到 | 開什麼 |
| --- | --- | --- |
| 輕身術（二段跳） | 煉氣圓滿 | 高一層的平台（已做：`scripts/cultivation.gd` 的 MOVEMENT_SKILLS） |
| 踏葉（牆跳） | 築基 | 兩面牆之間往上爬 |
| 御風（滑翔） | 築基中期事件 | 跨大斷崖 |
| 水遁 | 雲夢澤主線 | 水下區域 |
| 穿牆（土遁） | 金丹 | 薄牆後的暗室 |
| 御劍 | 元嬰 | 自由飛行一小段 |

身法是地圖探索的主要門檻（見 [世界地圖](world-map.md)），所以一律由主線或境界給，不放在付費機緣裡。

### 心法：仙、魔、佛

心法是被動能力，依「正邪」與「仁殺」兩軸開放：

| 分支 | 開放條件 | 風格 | 例子 |
| --- | --- | --- | --- |
| 仙心 | 正邪 ≥ 20 | 穩、續航 | 打坐回復加快、受致命傷時護體一次、靈獸親近 |
| 魔心 | 正邪 ≤ -20 或 仁殺 ≤ -20 | 險、爆發 | 擊殺回氣血、低氣血時傷害提高、可以吞妖丹修煉 |
| 佛心 | 正邪介於 -20～20 且 仁殺 ≥ 20 | 化解 | 讓敵人投降而非死亡、心魔試煉多一個「放下」選項、淨化魔氣 |

- 心性變了，不符合條件的分支會「封印」：點數不退，效果暫停，回到條件內就恢復。這讓心性的選擇有代價，也讓玩家可以回頭。
- 佛心分支在遊戲裡任何人都能點；佛緣（付費）給的是佛緣事件與禪功，不是佛心本身。

### 緣法（機緣專屬術法）

仙緣、魔緣、佛緣事件會給「緣法」：機緣專屬的術法或心法節點，掛在對應功法樹或心法分支旁邊。

- 緣法和一般術法同一個數值預算，提供的是不同玩法（例如仙緣「引鶴」召一隻鶴帶你飛過斷崖再回來；魔緣「血契」把一隻打敗的妖收成短暫的戰鬥夥伴）。
- 免費玩家遇到機緣事件時一樣拿得到，只是遇得少。

## 點數從哪來

| 來源 | 點數 |
| --- | --- |
| 突破境界 | 功法點 3、心法點 2 |
| 每個小境界（修為 25%、50%、75%） | 功法點 1 |
| 悟道（事件或打坐時頓悟） | 功法點 1，或直接學會某個節點 |
| 功法殘頁（掉落） | 解鎖該功法的一個節點，不花點數 |

「悟道」是導演可以生成的事件結局：例如在瀑布下看水流有所領悟，學會劍訣的「流水」節點。

## 給導演用的技能表

新增 `content/skills.json`，和 `loot.json` 一樣是遊戲的資料：

```json
{
  "skill.qingyun_sword.qi_slash": {
    "name": "劍氣斬",
    "school": "青雲劍訣",
    "tier_min": "煉氣",
    "kind": "art",
    "requires": [],
    "teachable": true
  }
}
```

- 導演只能傳授 `teachable` 為 true、`tier_min` 不高於玩家境界的節點。
- 內容包結局用新的 effect（例如 `grant_skill`），或沿用現有的掉落機制給「功法殘頁」物品。要不要新增 effect，和 M2 串討論：用殘頁物品不需改引擎，比較快。
- 驗證器檢查內容包引用的技能 id 都在 `skills.json`。
