# 人物外觀：容貌、衣著、時裝與配件

狀態：v0.1 提案（2026-11-01）。第一批已做進遊戲（Y 鍵打開衣櫃）；數量、解鎖條件與收費建議都是起始值，靠試玩調。武器外觀另見「規劃 Zetas 武器與功法系統」，這份不含武器。

## 一句話

玩家可以捏自己的容貌（臉型、眼、眉、髮型、髮色），在衣櫃換衣著與三種配件（頭飾、背飾、腰飾）。外觀一律不加數值，取得方式跟著境界、心性、因果與機緣走，讓玩家「看一眼就知道這個人走過什麼路」。

## 原則

1. **外觀只是外觀。** 衣服、配件不加攻防，戰力只看境界、功法與武器。這樣收費的外觀不會變成賣戰力（[收費文件](fate-monetization.md) 的原則 2），玩家也不用為了數值穿自己不喜歡的衣服。
2. **剪影先行。** 每件外觀先看剪影能不能一眼分出來：飄帶、披風、帷帽、高馬尾都是輪廓上的大變化；顏色和紋樣是第二層（[美術風格指南](art-direction.md) 第 4 點）。
3. **境界、心性、因果看得見。** 解鎖條件盡量用遊戲裡已經發生的事，而不是買或刷：
   - 境界：築基發內門青衫與銀冠，金丹師父賜雲紋道袍，元嬰頭髮轉霜白。
   - 心性：仁殺 -30 以下髮色才能選「赤霞」；心性回頭了，赤霞就穿不了，自動換回墨黑。
   - 因果：放走白狐才有狐毛香囊；通過築基心魔才有照影墨衣。
   - 機緣：仙緣、魔緣事件給對應的外觀（見「收費」）。
4. **三道三色。** 仙是月白、天青、淡金，魔是墨黑、焦茶、朱紅，佛是赭石、沙黃、金箔（美術指南第 3 點）。一般門派服維持低飽和，三道外觀一穿上就該跳出來。
5. **以宋明服制為底，簡化、誇張。** 交領右衽、寬袖長袍是基本型；袖子更長、披帛更飄。

| 衣櫃 | 腰飾 | 酒葫蘆、白玉佩、符籙、狐毛香囊 | 可不戴 |

**衣著與時裝的差別**：兩者用同一個衣櫃、同樣的欄位，差別只在來源。

- **衣著**：門派制服、境界賞賜、劇情得到的衣服，所有玩家照進度都拿得到。每個門派有一套從外門到真傳的升級線。
- **時裝**：機緣事件、節慶活動、成就給的外觀，風格更張揚（三道三色、特殊剪影）。不影響主線，不給數值。

`content/wardrobe.json` 每個選項有 `line`（青雲／散修／心魔／因果／仙／魔），之後衣櫃可以照這個分頁。

## 臉型與髮型的設計

- 角色比例是 1:7 頭身、頭部放大 1.25 倍（美術指南「角色」），臉在場景裡只有幾十像素；臉型的差別主要在對話頭像看得出來，場景裡主要靠髮型與頭飾分辨。
- 所以**髮型做大、做剪影**：高馬尾甩出頭頂、散髮往後散開、雙丫髻兩個髻，在場景裡都看得出來。
- 眉毛位置往下移到瀏海下緣，否則被瀏海蓋住（原本 NPC 的眉沒有改）。
- 不分男女：每個選項都可以任意搭，玩家自己決定角色看起來像誰。對話裡稱呼仍用「道友」「師弟／師妹」等由導演依劇情決定的稱謂，之後可在捏臉加一個「稱呼」選項。
- 捏臉目前隨時可以改、不花錢。之後若要讓「易容」有份量，可以改成要一顆「易容丹」（商店或任務給），但不建議收費。

## 收費建議

延續 [仙緣、魔緣與佛緣](fate-monetization.md)：收費賣的是機緣多寡，外觀是機緣的獎勵之一，不另外開「外觀商城」。

1. **機緣外觀跟著機緣事件走。** 流雲仙裳、蓮華冠、流雲披帛由仙緣事件給，墨焰魔袍、半面魔紋、墨焰披風由魔緣事件給（遊戲用 `has_item` 判斷，事件掉落同名物品就解鎖）。緣卡讓這些事件來得比較勤，所以訂閱的玩家會比較早湊齊，但免費玩家慢慢也拿得到。
2. **到期不收回。** 跟月卡規則一樣，拿到的外觀永遠是你的。
3. **每 30 天一件「緣衣」。** 緣卡有效期間每 30 天送一件當期限定的配件或配色（例如中秋的玉兔腰飾），過期後不再發，但已領的留著。這是給訂閱者的「看得見的身分」，不影響數值。
4. **佛緣外觀只能靠佛緣線。** 不賣，維持「佛緣是走出來的」這件事。
5. **不做抽卡、不做機率型外觀箱。** 和緣分值「看得見、算得出」的原則一致，也避開機率型商品的揭露爭議。
6. **之後如果要單賣外觀**：只賣不在任何玩法裡出現的節慶外觀，明碼標價、直接買到；門派服、境界服、因果外觀永遠不賣。

## 實作

- **分層立繪**：`tools/inkpaint/wardrobe.py` 用跟 NPC 同一套筆觸（`figures.py`）把每個選項畫成一張透明圖層，`python tools/paint_art.py --wardrobe` 重畫，輸出 `art/wardrobe/` 與位移 `content/wardrobe_layers.json`。髮色是每色各畫一份（不在遊戲裡染色），墨線才不會被染到。
- **疊圖順序**（後到前）：背飾、後髮、後袖、背劍、袍身、腰飾、髮底、臉、瀏海與髮髻、眼、眉、頭飾、前袖與手。`scripts/wardrobe.gd` 照這個順序疊成一張跟 `player.disciple.png` 一樣大的圖，再給原本的描邊光暈著色器，所以遊戲裡其他地方（殘影、打坐、頭像）都不用改。
- **選項與解鎖**：`content/wardrobe.json`；`unlock` 是引擎條件（`tier_at_least`、`flag`、`karma`、`has_item`……），全部成立才解鎖；`source` 是沒解鎖時告訴玩家怎麼拿。
- **存檔**：`state.game_data["look"]`。讀檔時不認得的選項換回預設；條件不成立的（例如心性變了）也換回預設，存檔裡的選擇保留，條件又成立就自動穿回來。
- **衣櫃**：Y 鍵（手把 R3），事件進行中不能開。↑↓ 選欄、←→ 換；已解鎖的立刻穿上並存檔，沒解鎖的只是試穿，關掉換回。新解鎖時紀錄會提一句「衣櫃多了：……」。
- **加一件新衣服**：在 `wardrobe.py` 的 `OUTFITS`（或 `HEADWEAR`、`BACKS`、`WAISTS`）加長相，在 `content/wardrobe.json` 加名稱與條件，跑 `--wardrobe`；測試會檢查每個選項都有圖層。

## 之後要做的事

1. 對話頭像：主角頭像現在是從全身圖裁出來的，之後畫半身表情立繪時，容貌選項要一起分層。
2. 染色：衣著分「主色、鑲邊色」兩個可染區，染料當作採集與任務獎勵（要把袍身和鑲邊拆成兩層畫）。
3. 境界外觀（美術指南「境界看得見」）：金丹周身墨氣、元嬰腳下雲氣，疊在衣櫃之外，所有外觀都吃得到。
4. 衣櫃分頁（依 `line`）與「整套存檔」（存 3 套常用外觀一鍵換）。
5. 第一批是程式畫的底稿；定稿圖畫好後，直接蓋掉 `art/wardrobe/` 同名檔即可，位移照 `wardrobe_layers.json`。
6. NPC 也改用分層立繪，讓導演生成的 NPC 可以隨機搭配容貌與門派服，變體不再只靠 `_a`、`_b`。
