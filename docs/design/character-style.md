# 人物造型：熱門仙俠／橫軸作品的造型手法與 Zetas 的元素清單

狀態：v0.1（2026-11-03）。Kc：「人物造型重新設計、元素不太夠，可以找熱門的設計來參考」。
原則跟 [reference-study.md](reference-study.md) 一樣：**只借手法，不借角色**。下面每一條都是業界常見的做法，不對應任何一部作品的特定角色。

## 一、熱門作品怎麼讓角色「有遊戲感」

參考對象：國產仙俠 MMO（天涯明月刀、逆水寒、劍網三一類的古風時裝）、古劍奇譚／仙劍系列的換裝、原神璃月角色、鬼谷八荒／太吾繪卷的立繪、楓之谷的橫軸大頭身、九日（Nine Sols）／斬妖行等 2D 動作遊戲。

| # | 手法 | 為什麼有效 | 原本的 Zetas |
| --- | --- | --- | --- |
| 1 | **三層疊穿**：內襯（白）＋袍＋外罩（半臂、褙子、大氅），三層明度不同 | 一眼看出「穿了好幾件」，比單色長袍豐富，換外罩就像換一套 | 只有一件袍，各套只是換顏色 |
| 2 | **腰是視覺中心**：寬腰封＋繩結＋長垂帶／流蘇 | 把身體切成上下兩段、給一個顏色焦點；垂帶跑動時是第二道飄動剪影 | 一條細腰帶 |
| 3 | **衣緣鑲邊與紋樣只放在邊上**（領、袖口、下襬、前襟），中間留素 | 小畫面上「邊框」比「滿版花紋」讀得清楚，也符合宋明服制 | 只有部分衣服有下襬色帶 |
| 4 | **肩頸加一件**：雲肩、護肩、毛領 | 肩線是側面剪影最寬的地方，加東西最顯眼；也最能分出文／武／地域 | 沒有 |
| 5 | **袖口分文武**：廣袖寬鑲邊 vs. 束袖護腕 | 一看袖子就知道是道袍還是勁裝 | 只有寬／窄兩種，沒細節 |
| 6 | **下襬開衩＋長靴／綁腿** | 露出腿就有動感，劍修、散修的利落感都靠它 | 長袍蓋到腳 |
| 7 | **頭上一個亮點**：步搖、髮帶、髮簪 | 臉在橫軸畫面只有十幾像素，頭上的色點和飄動髮帶反而是辨識重點 | 只有一根金簪 |
| 8 | **大頭身比** | 楓之谷式橫軸都把頭放大，表情與髮型才撐得起來 | 頭 1.25 倍 |
| 9 | **60-30-10 配色＋一個強調色** | 主色、副色之外留一個朱紅／金點綴（穗子、繩結），畫面才「亮」 | 多數衣服只有兩色 |
| 10 | **三道三色**（已在美術指南）：仙月白天青淡金、魔墨黑朱紅、佛赭石金箔 | 收費外觀一穿上就跳出來 | 保留 |

## 二、做進遊戲的元素清單（這次）

程式畫在 `tools/inkpaint/figures.py`（新 spec 欄位，NPC 不設就不受影響）、`tools/inkpaint/wardrobe.py`（各套怎麼配）。

| 元素 | spec 欄位 | 用在 |
| --- | --- | --- |
| 外罩：半臂／褙子／大氅（含側開衩、外袖） | `overcoat` | 月白弟子袍、內門青衫（半臂）、散修（長褂）、雲紋道袍、墨焰魔袍（大氅） |
| 寬腰封＋繩結＋兩條垂帶＋流蘇 | `waist_wrap` | 全部衣著 |
| 寬領緣（多露一道中衣白） | `collar` | 全部衣著 |
| 袖口鑲邊／護腕 | `cuff` | 全部衣著 |
| 下襬回紋 | `hem_pattern` | 弟子袍、內門、道袍、劍裝 |
| 前襬開衩露褲腿 | `split` | 散修、照影墨衣、青雲劍裝 |
| 長靴、綁腿 | `boots`、`leg_wraps` | 多數衣著、外門短褐 |
| 多層紗下襬 | `skirt_layers` | 流雲仙裳 |
| 步搖、雙髻髮帶、馬尾髮帶 | `hair_ornament` | 玩家全部髮型 |
| 頭放大到 1.36 倍 | `head_scale`（只有玩家） | 玩家 |
| **新衣著**：青雲劍裝（劍修勁裝） | | 一開始就有 |
| **新欄位：肩飾**：青雲肩（雲肩，築基）、玄鐵護肩（一開始就有）、雪狐毛領（放走白狐＋築基） | `shoulder_items` | 衣櫃「肩飾」欄 |

## 三、還沒做、值得做的

1. **鏡頭或角色再放大**：玩家在畫面上只有 88px 高，細節（回紋、步搖）在場景裡幾乎看不到，剪影與色塊才是主力。可考慮戰鬥外鏡頭拉近 1.2 倍。
2. **定稿圖**：這批還是程式畫底稿。ComfyUI（ubt015）img2img 重繪可以提質感，但衣櫃是分層圖，要逐層重繪或改成「整套重繪＋配件分層」，另開一串評估。
3. ~~飄動~~（2026-11-03 已做）：背飾飄帶、後髮、髮帶長尾另疊一張飄動層，衣襬（腰以下）在身體那張上擺；ink_halo.gdshader 的 flow／flutter 參數，player.gd 依站、跑、起跳、下落、御風、御劍給不同幅度。對照圖 `zetas-attire/flow-poses.png`、`flow-motion.gif`；截圖工具 `tools/flow_shots.gd`。腰封垂帶還在腰封那層，跟著衣襬一起擺。
4. **姿勢**：全部同一個站姿；可做一個「持劍待機」姿勢給劍裝。
5. **NPC 也用這套層次**：門派服（[attire.md](attire.md) 的門派表）照第二節的欄位配，導演生成的 NPC 就能隨機組出不同造型。
