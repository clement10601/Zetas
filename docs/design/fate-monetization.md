# 仙緣、魔緣與佛緣：收費與事件觸發

狀態：v0.1 提案（2026-10-31）。數字都是起始值，要靠試玩調。

## 一句話

玩家可以訂「仙緣月卡」、「魔緣月卡」或兩張都訂。訂閱期間，對應的機緣事件來得比較勤；免費玩家也會遇到，只是很少。兩張都訂、而且心性走在仙魔之間，才會遇到「佛緣」事件。（2026-10-31 Kc 選定月卡。）

## 原則

1. **主線完整免費。** 地圖、境界、技能樹、主線結局、宗門與因果事件，免費玩家全都玩得到。收費賣的是「機緣多寡」和佛緣這條線，不賣主線。
2. **買的是頻率，不是戰力。** 機緣事件給的獎勵和一般事件在同一個數值預算內（見下方「獎勵」）。買了會遇到更多故事、更多樣的技能與道具，但不會讓數值直接壓過免費玩家。
3. **看得見、算得出。** 機緣用「緣分值」累積，滿了必定觸發，不用暗骰。玩家在角色面板看得到三條緣分值和每天漲多少。這樣也避開「付費機率」的爭議（見「法規」）。
4. **自己的選擇也算數。** 行善累積仙緣、殺伐累積魔緣。免費玩家只要玩法夠鮮明，也能把某一條緣分推得比較快。

## 三種緣

| 緣 | 題材 | 代表事件 | 在哪裡發生 |
| --- | --- | --- | --- |
| 仙緣 | 仙人遺府、謫仙、靈獸認主、天材地寶 | 雲中仙府開門、老道贈半卷殘經、白鶴銜來一枚玉簡 | 有 `shrine`、`cave`、`peak`（新增）標籤的區塊；東海蓬萊（見地圖文件） |
| 魔緣 | 魔道傳承、血契、上古魔頭殘魂、禁術 | 墮魔散修臨死託付魔功、血池裡的聲音、與魔物立契 | 有 `cave`、`den`、`ravine` 標籤的區塊，多在夜裡；幽冥血海 |
| 佛緣 | 放下、渡化、因果了結 | 遊方老僧點破心魔、渡化一路追殺你的仇家、在仙魔之間選第三條路 | 有 `shrine`、`village` 標籤的區塊；西漠靈山 |

仙緣和魔緣不是好壞之分。仙緣偏「得」，魔緣偏「取」，兩條線都有善惡難斷的選擇。

## 緣分值

每條緣各有一個 0～100 的緣分值，存在遊戲的 `game_data`（引擎不認得這個概念，見「實作」）。

| 來源 | 仙緣 | 魔緣 | 佛緣 |
| --- | --- | --- | --- |
| 每過一天（免費） | +4 | +4 | 0 |
| 每過一天（該緣月卡有效） | +12 | +12 | +8（兩張都有效才有） |
| 事件結局讓「仁殺」往仁厚移動 | +5 | | |
| 事件結局讓「正邪」往偏正移動 | +3 | | |
| 事件結局讓「仁殺」往嗜殺移動 | | +5 | |
| 事件結局讓「正邪」往偏邪移動 | | +3 | |
| 放過或渡化本來可以殺的對手 | | | +6 |
| 突破境界 | +10 | +10 | +10 |

- 緣分值到 100：遊戲設旗標 `fate.xian_ready`（魔緣 `fate.mo_ready`、佛緣 `fate.fo_ready`）。下一次走進合適的地圖、時辰對了，機緣事件就上場。觸發後緣分值歸零。
- 同一天最多觸發一個機緣事件，避免一次全部爆出來。
- 行為加成每天每條最多 +15，避免刷同一種小事。

### 大概多久遇到一次

用「一個現實小時約過 3 個遊戲日」估（之後依實際節奏調）：

| 玩家 | 每條緣大約多久一次 |
| --- | --- |
| 免費、玩法平均 | 約 20 遊戲日，也就是 6～7 小時一次 |
| 免費、玩法偏向某一邊 | 偏的那邊約 10 遊戲日，3～4 小時一次 |
| 月卡有效 | 約 7 遊戲日，2～3 小時一次；配合玩法約 5 遊戲日 |
| 兩張都訂 | 仙、魔各自如上，佛緣約 10 遊戲日一次（且要符合心性條件） |

免費玩家每晚玩兩小時，大約一週遇到一次仙緣或魔緣，知道有這種事，但不會常常有。

## 佛緣的解鎖條件

佛緣要同時符合：

1. 仙緣、魔緣月卡都在有效期內。
2. 仙緣和魔緣事件各至少完成過一個（玩家真的走過兩邊）。
3. 心性在中間：「正邪」介於 -20 到 20 之間，而且「仁殺」不低於 0。

第 3 條讓佛緣不只是「付錢就有」：一路殺到底的魔修，訂了也要先回頭。

免費或只訂一張的玩家，在築基和金丹各會遇到一次遊方老僧（手寫事件），老僧只說「施主與我佛緣分未到」，留個伏筆，不給獎勵。

## 機緣事件長什麼樣

- 每條緣以「機緣線」組織：一條線 3～5 個事件，跨好幾個境界。例如仙緣線「雲中仙府」：煉氣撿到殘破玉簡 → 築基找到仙府入口 → 金丹通過仙府試煉 → 元嬰仙府認主，成為洞府。
- 每條線的第一個事件手寫，後面由導演依玩家先前的選擇生成（用 `request_followup`）。
- 每個境界、每條緣準備 2 條以上的手寫開頭，避免所有玩家第一次遇到的都一樣。
- 仙緣與魔緣可以互相牽動：拿了仙府傳承，魔道就有人來搶；收了魔功，正道師長會察覺。

## 獎勵

機緣事件的獎勵上限和同境界一般事件一樣，走 `ruleset.json` 的 `loot_caps`。差別在「種類」：

- 機緣專屬的功法殘頁與術法（見技能樹文件的「緣法」分支）。這些術法是不同玩法，不是更強的數值。
- 機緣專屬的外觀：服飾、法器外形、坐騎。
- 洞府與靈獸。

## 實作（和引擎、導演的分工）

緣分值、旗標、觸發條件用引擎現有功能就做得到；補貨與後續要先在 ZeWorld 做一個小改動（M2 串 2026-10-31 確認）。

- **緣分值** 存在 `WorldState.game_data["fate"]`，遊戲自己算，每過一天、每個事件結局時更新。
- **旗標**：緣分值滿 100 時遊戲設 `fate.xian_ready` 等旗標；觸發後清掉。
- **內容包**：觸發條件 `all` 裡放 `{"type": "flag", "key": "fate.xian_ready", "equals": true}`，再加地圖標籤、時辰。`priority` 設高（例如 80），旗標一成立就優先上場；不會和心魔衝突，心魔的 gate 是 `tier_up` 事件。佛緣另加 `karma` 條件。
- **判斷哪條緣**：一律看引擎寫入的 `meta.request_tag`（`fate_xian` / `fate_mo` / `fate_fo`），不要依賴模型自己寫的 `meta.tags`，模型可能漏寫。
- **導演補貨**：遊戲每天每個地區補一次一般事件（目標 3），每條緣再各補一次（月卡有效目標 2、沒有目標 1），各自帶自己的 `tag` 與 `gate: [{"type": "flag", "key": "fate.xian_ready", "equals": true}]`。
- **訂閱狀態** 從平台或帳號伺服器查，連同到期日快取在存檔外，不寫進 `save.json`，避免改存檔就解鎖（見「月卡」）。

需要的引擎改動（M2 串負責，約一個 PR）：

1. `DirectorClient.restock()` 加 `options`（tag、gate），存貨只算同一個 `request_tag` 的包，一般補貨只算沒有 `request_tag` 的包；送出中的請求與失敗冷卻改用「地區＋tag」計。
2. `request_followup` 產生的後續記下來源包的 `request_tag`，導演生成時當預設 tag 寫回，機緣線的後續才會留在同一條緣。

## 成本

機緣事件大多由導演生成，生成會花 Claude API 費用，所以收費要蓋得住成本。

- 2026-10-31 實測：一個內容包約 5k 輸出 token、快取後非快取輸入約 650 token、快取讀取約 9.2k token。用 Opus 5.5 牌價（輸入 US$4、輸出 US$20、快取讀取 US$0.20，每百萬 token）算，**一包約 US$0.10**。
- 即時台詞改用 Sonnet 5.5，一句不到 US$0.01。
- 訂閱玩家約 2～3 小時遇一次機緣，加上後續與補貨，估計一小時生成 1～2 包，約 US$0.1～0.2。玩 100 小時約 US$10～20。

降低成本的做法（依優先順序）：

1. **共用池**：同一個地區、境界的機緣開頭，先生成一批、人工挑過後給所有玩家用，只做最後一哩的台詞個人化。只有「後續」才為個別玩家生成。
2. **只為有效月卡的緣多補貨**（上一節）。
3. **導演改用較便宜的設定**：用 bench 比較 Opus 5.5 low effort 與 Sonnet 5.5 的通過率，品質守得住就換。
4. **每日生成上限**：每位玩家每遊戲日最多請導演生成 3 包，超過就從池裡拿已有的。

## 月卡

2026-10-31 Kc 選定月卡（另兩個選項是買斷 DLC、消耗型「緣香」）。好處是收入跟著生成成本走：玩得越多、生成越多，也一直有在付費。

### 方案

| 方案 | 效果 |
| --- | --- |
| 仙緣月卡 | 30 天內仙緣每天 +12，仙緣事件補貨目標 2 |
| 魔緣月卡 | 30 天內魔緣每天 +12，魔緣事件補貨目標 2 |
| 仙魔雙修（兩張合訂，打折） | 兩者皆有，加上佛緣每天 +8 與佛緣事件 |

佛緣不單賣。售價等共用池做出來、量到每位訂閱者每月實際生成成本後再定（見「成本」），目標是成本不超過月費的三成。

### 到期與續訂

- **到期後拿到的東西都留著**：已完成事件的獎勵、學會的緣法、洞府、靈獸、外觀一律不收回。到期只影響「之後」緣分值漲多快。
- **緣分值不歸零**：到期時累積到一半的緣分值保留，之後照免費速度繼續漲。
- **機緣線不中斷**：已經開始的機緣線，後續事件照樣會來（因果後續是遊戲的一部分），只是新的機緣線開頭變少。
- **佛緣**：兩張月卡中任一張到期，就不會再開新的佛緣事件；已開始的佛緣線可以走完。
- 續訂前 3 天在主選單提示一次，不在遊戲中途跳出。

### 單機遊戲的連線問題

月卡要查訂閱狀態，但遊戲本體是單機：

- 啟動時連得上就向平台／帳號伺服器查一次，把到期日快取在本機（加簽章，避免手改）。
- 連不上時用快取的到期日，最多寬限 7 天；過了寬限期照免費速度算，不影響其他玩法。
- 導演本來就要連網，訂閱查詢可以和導演服務放在同一個後台。

### 平台

- 2026-10-31 查過，見 [月卡在 Steam 上怎麼收](steam-subscription.md)：Steam 有定期扣款、單機也能用，但 Valve 說支援不完整，而且每款遊戲一位玩家只能有一份扣款協議（仙、魔兩張分開自動續訂做不到）。Steam 版的遊戲內購買必須走 Steam 錢包，所以不做自己的帳號與金流。
- 建議先用一般微交易賣「30 天緣卡」（不自動續訂、可疊加），之後再考慮加自動續訂。
- 如果之後加自動續訂，購買頁要寫明金額、週期、怎麼取消，取消要和訂閱一樣容易。

### 和成本的關係

- 每位訂閱者每遊戲日最多為他個人生成 3 包（「成本」第 4 點），所以每月成本有上限，可以反推月費下限。
- 用「成本」一節的估算：重度玩家一個月 60 小時、每小時 US$0.1～0.2，約 US$6～12；做了共用池後要再量一次，才能定價。
- Steam 抽 30% 後，照現在的成本一般訂閱者就會讓單卡虧錢；試算與「每 30 天個人生成額度」的建議見 [月卡在 Steam 上怎麼收](steam-subscription.md)。

## 法規與玩家觀感

- 台灣對線上遊戲的「機率型商品」有揭露規定。我們用確定性的緣分值，買的東西沒有機率成分，風險較低；但上架前仍要請熟悉的人確認，特別是如果之後改成消耗型。月卡是定期付費，要遵守自動續訂的揭露與取消規定。
- 遊戲內把三條緣分值、每天漲多少、佛緣條件寫清楚，不要讓玩家猜。
- 不在心魔試煉、戰鬥中或剛失敗時跳購買提示。購買入口只放在角色面板和主選單。
- 不做限時特價倒數這類壓迫手法。
