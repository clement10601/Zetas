# 仙緣、魔緣與佛緣：收費與事件觸發

狀態：v0.1 提案（2026-10-31）。數字都是起始值，要靠試玩調。

## 一句話

玩家可以買「仙緣」、「魔緣」或兩個都買。買了之後，對應的機緣事件來得比較勤；免費玩家也會遇到，只是很少。兩個都買、而且心性走在仙魔之間，才會遇到「佛緣」事件。

## 原則

1. **主線完整免費。** 地圖、境界、技能樹、主線結局、宗門與因果事件，免費玩家全都玩得到。收費賣的是「機緣多寡」和佛緣這條線，不賣主線。
2. **買的是頻率，不是戰力。** 機緣事件給的獎勵和一般事件在同一個數值預算內（見下方「獎勵」）。買了會遇到更多故事、更多樣的技能與道具，但不會讓數值直接壓過免費玩家。
3. **看得見、算得出。** 機緣用「緣分值」累積，滿了必定觸發，不用暗骰。玩家在角色面板看得到三條緣分值和每天漲多少。這樣也避開「付費機率」的爭議（見「法規」）。
4. **自己的選擇也算數。** 行善累積仙緣、殺伐累積魔緣。免費玩家只要玩法夠鮮明，也能把某一條緣分推得比較快。

## 三種緣

| 緣 | 題材 | 代表事件 | 在哪裡發生 |
| --- | --- | --- | --- |
| 仙緣 | 仙人遺府、謫仙、靈獸認主、天材地寶 | 雲中仙府開門、老道贈半卷殘經、白鶴銜來一枚玉簡 | 有 `shrine`、`cave`、`peak`（新增）標籤的區塊；東海蓬萊（見地圖文件） |
| 魔緣 | 魔道傳承、血契、上古魔頭殘魂、禁術 | 墮魔散修臨死託付魔功、血池裡的聲音、與魔物立契 | 有 `cave`、`den`、`ravine` 標籤的區塊，多在夜裡；幽冥血海 |
| 佛緣 | 放下、渡化、因果了結 | 遊方老僧點破心魔、渡化一路追殺你的仇家、在仙魔之間選第三條路 | 有 `shrine`、`village` 標籤的區塊；西漠靈山 |

仙緣和魔緣不是好壞之分。仙緣偏「得」，魔緣偏「取」，兩條線都有善惡難斷的選擇。

## 緣分值

每條緣各有一個 0～100 的緣分值，存在遊戲的 `game_data`（引擎不認得這個概念，見「實作」）。

| 來源 | 仙緣 | 魔緣 | 佛緣 |
| --- | --- | --- | --- |
| 每過一天（免費） | +4 | +4 | 0 |
| 每過一天（已購買該緣） | +12 | +12 | +8（兩個都買才有） |
| 事件結局讓「仁殺」往仁厚移動 | +5 | | |
| 事件結局讓「正邪」往偏正移動 | +3 | | |
| 事件結局讓「仁殺」往嗜殺移動 | | +5 | |
| 事件結局讓「正邪」往偏邪移動 | | +3 | |
| 放過或渡化本來可以殺的對手 | | | +6 |
| 突破境界 | +10 | +10 | +10 |

- 緣分值到 100：遊戲設旗標 `fate.xian_ready`（魔緣 `fate.mo_ready`、佛緣 `fate.fo_ready`）。下一次走進合適的地圖、時辰對了，機緣事件就上場。觸發後緣分值歸零。
- 同一天最多觸發一個機緣事件，避免一次全部爆出來。
- 行為加成每天每條最多 +15，避免刷同一種小事。

### 大概多久遇到一次

用「一個現實小時約過 3 個遊戲日」估（之後依實際節奏調）：

| 玩家 | 每條緣大約多久一次 |
| --- | --- |
| 免費、玩法平均 | 約 20 遊戲日，也就是 6～7 小時一次 |
| 免費、玩法偏向某一邊 | 偏的那邊約 10 遊戲日，3～4 小時一次 |
| 已購買 | 約 7 遊戲日，2～3 小時一次；配合玩法約 5 遊戲日 |
| 兩個都買 | 仙、魔各自如上，佛緣約 10 遊戲日一次（且要符合心性條件） |

免費玩家每晚玩兩小時，大約一週遇到一次仙緣或魔緣，知道有這種事，但不會常常有。

## 佛緣的解鎖條件

佛緣要同時符合：

1. 兩種緣都買了。
2. 仙緣和魔緣事件各至少完成過一個（玩家真的走過兩邊）。
3. 心性在中間：「正邪」介於 -20 到 20 之間，而且「仁殺」不低於 0。

第 3 條讓佛緣不只是「付錢就有」：一路殺到底的魔修，買了也要先回頭。

免費或只買一種的玩家，在築基和金丹各會遇到一次遊方老僧（手寫事件），老僧只說「施主與我佛緣分未到」，留個伏筆，不給獎勵。

## 機緣事件長什麼樣

- 每條緣以「機緣線」組織：一條線 3～5 個事件，跨好幾個境界。例如仙緣線「雲中仙府」：煉氣撿到殘破玉簡 → 築基找到仙府入口 → 金丹通過仙府試煉 → 元嬰仙府認主，成為洞府。
- 每條線的第一個事件手寫，後面由導演依玩家先前的選擇生成（用 `request_followup`）。
- 每個境界、每條緣準備 2 條以上的手寫開頭，避免所有玩家第一次遇到的都一樣。
- 仙緣與魔緣可以互相牽動：拿了仙府傳承，魔道就有人來搶；收了魔功，正道師長會察覺。

## 獎勵

機緣事件的獎勵上限和同境界一般事件一樣，走 `ruleset.json` 的 `loot_caps`。差別在「種類」：

- 機緣專屬的功法殘頁與術法（見技能樹文件的「緣法」分支）。這些術法是不同玩法，不是更強的數值。
- 機緣專屬的外觀：服飾、法器外形、坐騎。
- 洞府與靈獸。

## 實作（和引擎、導演的分工）

引擎現有功能就夠，不需要先改 ZeWorld：

- **緣分值** 存在 `WorldState.game_data["fate"]`，遊戲自己算，每過一天、每個事件結局時更新。
- **旗標**：緣分值滿 100 時遊戲設 `fate.xian_ready` 等旗標；觸發後清掉。
- **內容包**：機緣事件的 `meta.tags` 加 `fate.xian` / `fate.mo` / `fate.fo`；觸發條件 `all` 裡放 `{"type": "flag", "key": "fate.xian_ready", "equals": true}`，再加地圖標籤、時辰。`priority` 設高（例如 80），旗標一成立就優先上場。佛緣另加 `karma` 條件。
- **導演補貨**：遊戲請導演補機緣事件時帶 `tag: "fate_xian"` 與 `gate: [{"type": "flag", "key": "fate.xian_ready", "equals": true}]`。已購買的緣，每個地區保持 2 個沒玩過的機緣事件；沒購買的緣只保持 1 個，省生成費用。
- **購買狀態** 存在存檔外的授權資料（Steam DLC 擁有權），不寫進 `save.json`，避免改存檔就解鎖。

需要和 M2 串確認的事：每日補貨排程要能依 tag 分開計數；`request_followup` 生成的機緣線後續要保留 `fate.*` tag。

## 成本

機緣事件大多由導演生成，生成會花 Claude API 費用，所以收費要蓋得住成本。

- 2026-10-31 實測：一個內容包約 5k 輸出 token、快取後非快取輸入約 650 token、快取讀取約 9.2k token。用 Opus 5.5 牌價（輸入 US$4、輸出 US$20、快取讀取 US$0.20，每百萬 token）算，**一包約 US$0.10**。
- 即時台詞改用 Sonnet 5.5，一句不到 US$0.01。
- 已購買的玩家約 2～3 小時遇一次機緣，加上後續與補貨，估計一小時生成 1～2 包，約 US$0.1～0.2。玩 100 小時約 US$10～20。

降低成本的做法（依優先順序）：

1. **共用池**：同一個地區、境界的機緣開頭，先生成一批、人工挑過後給所有玩家用，只做最後一哩的台詞個人化。只有「後續」才為個別玩家生成。
2. **只為買了的緣多補貨**（上一節）。
3. **導演改用較便宜的設定**：用 bench 比較 Opus 5.5 low effort 與 Sonnet 5.5 的通過率，品質守得住就換。
4. **每日生成上限**：每位玩家每遊戲日最多請導演生成 3 包，超過就從池裡拿已有的。

## 售價與賣法（待決）

這是要 Kc 決定的事，先列選項：

| 賣法 | 好處 | 壞處 |
| --- | --- | --- |
| **買斷 DLC**（建議） | 單機玩家最能接受；Steam 好上架；沒有「機率型商品」疑慮 | 生成成本會隨遊玩時數一直累積，要靠共用池與上限控制 |
| 月卡（每月緣分加成） | 收入跟著成本走 | 單機遊戲玩家反感；要做帳號與續訂 |
| 消耗型「緣香」（燒一炷加速一陣子） | 成本和收入最對得上 | 最像手遊課金，和「主線免費、看得見」的原則衝突 |

建議：仙緣、魔緣各賣一個買斷 DLC，兩個一起買打折；佛緣不單賣，兩個都有就送。售價等共用池做出來、量到每小時實際成本後再定。

## 法規與玩家觀感

- 台灣對線上遊戲的「機率型商品」有揭露規定。我們用確定性的緣分值，買的東西沒有機率成分，風險較低；但上架前仍要請熟悉的人確認，特別是如果之後改成消耗型。
- 遊戲內把三條緣分值、每天漲多少、佛緣條件寫清楚，不要讓玩家猜。
- 不在心魔試煉、戰鬥中或剛失敗時跳購買提示。購買入口只放在角色面板和主選單。
- 不做限時特價倒數這類壓迫手法。
