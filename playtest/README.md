# Zetas 封閉測試版

謝謝幫忙試玩！這是很早期的版本，畫面是水墨風的暫用素材，請把重點放在「發生了什麼事」。

## 怎麼玩

**網頁版：** 用電腦的 Chrome 或 Edge 打開 https://clement10601.github.io/Zetas/ ，第一次開啟會請你輸入存取碼（之後會記住）。第一次載入約 60 MB。

**Windows 版：** 解壓縮後執行 `Zetas.exe`。若 Windows 跳出 SmartScreen 警告，按「其他資訊」→「仍要執行」（測試版沒有數位簽章）。

| 按鍵 | 動作 |
| --- | --- |
| ← → / A D | 移動 |
| Alt / C / 空白 | 跳（↓＋跳 從平台往下跳；煉氣修為圓滿後空中再按一次是二段跳） |
| ↑ ↓ / W S | 爬繩子、藤蔓、梯子 |
| K | 御劍（元嬰後，空中按） |
| ↑ / W / E | 傳送點：走到相鄰地區；NPC 旁：交談 |
| J | 攻擊 |
| 空白 / Enter | 下一句對話 |
| 1–4 | 選擇 |
| T | 地圖：在青雲宗、青雲山腳、黑風嶺之間移動 |
| M | 打坐：增加修為、回滿氣血 |
| B | 修為圓滿時突破境界 |
| F5 / F9 | 存檔 / 讀檔（離開事件時也會自動存檔） |

## AI 事件

在 `Zetas.exe` 旁邊新增 `director_code.txt`，裡面只放你的個人存取碼（一行），請不要分享給別人。導演網址已經寫在 `director_url.txt`，不用改。有它遊戲才會連上 AI 導演，生成只屬於你的事件和台詞；連不上時遊戲照常，只是只有預先寫好的事件。每天的生成次數有上限，用完了隔天（台灣時間早上 8 點）重置。

建議至少玩 30 分鐘，或玩到築基。你的選擇會被記住，之後的事件會跟著變。

## 玩完之後

1. 把遊玩紀錄傳回來：`%APPDATA%\Zetas\playlog.jsonl`（在檔案總管網址列貼上 `%APPDATA%\Zetas` 就能找到）。檔案裡只有事件開始與結束、翻頁速度這類資料，沒有任何個人資訊。
2. 回答一個問題：**有沒有哪件事，你覺得只會發生在你身上？** 請用一兩句話描述，越具體越好。

存檔在同一個資料夾（`save.json`），想重新開始就刪掉它。
